- 摘要：Anthropic 于2026年7月6日发布 interpretability 研究，提出 Claude 内部存在名为 J-space 的 neural pattern 集合，对应 global workspace 理论。J-lens 技术可读取模型未输出文本情况下的内部“词级”表征；实验显示 Claude 可报告、控制 J-space 内容，并在多步推理中使用其中间步骤。干预 J-space 可改变模型回答（如将 Soccer 替换为 Rugby）。研究团队称 J-space 可用于检测 prompt injection、隐藏目标或伪造数据，并已开源核心方法与 Neuronpedia 交互 demo。
