# 今日 AI PM 行业雷达

## 1. 五段式日报

**产品 / 行业动态**：今天最强信号是企业 AI 从“能不能用最强模型”转向“能不能承担最强模型”。花旗、Adobe、Atlassian 等限制旗舰模型，说明 2B AI 产品的核心不只是能力，而是预算、权限、模型路由和可解释 ROI。

**GitHub / 工程信号**：Senior SWE-Bench、ghealth、video-use、设计工程师 Skills 都指向一个方向：AI 工程实践正在从“让模型写代码”走向“给 agent 提供可验证任务、结构化工具和可复用 skill”。

**论文 / 研究信号**：RLI 和 Senior SWE-Bench 更接近现实工作质量评估，说明下一阶段值得关注的不是单点 benchmark 分数，而是面向真实工作流的 eval、人工裁判质量和任务边界。

**工具 / 工作流信号**：Kimi K2.7 Code 进入 GitHub Copilot、Claude Code 更新、Google Cloud Workbench、Cloudflare AI traffic options 共同说明开发者工具正在围绕“成本、访问控制、环境连接、agent 可观测性”重组。

**风险 / 限制 / 反例**：RLI 仍只有 16.1% 专业自动化率，Senior SWE-Bench 最强 agent 仍大多失败，Google AI 用电增长和企业成本限制都提醒我们：AI PM 不能只讲能力跃迁，还要讲成本、质量和部署边界。
