# 今日 AI PM 行业雷达

## 1. 五段式日报

**产品 / 行业动态**：今天的主线不是单个模型发布，而是企业 AI 进入“可治理、可部署、可度量”的阶段。Claude Enterprise 把成本、价值、模型权限和支出告警产品化；Microsoft Frontier Company 把 AI 落地做成前线工程组织；Intuiface 则展示垂直场景里 agent 如何从提示词生成可交互体验。

**GitHub / 工程信号**：GitHub Copilot 浏览器工具 GA、agent session streaming、Page Agent、Sento 2.0 和 SGLang Skill 化开发共同说明：工程侧正在把 agent 能力落到真实页面、真实会话审计、可复刻技能、结果校准和长期记忆。对个人独立开发者来说，今天最值得动手的是 Page Agent 或 Sento 的最小复刻。

**论文 / 研究信号**：Apple 的“多智能体团队阻碍专家发挥”是今日最重要研究反例：自组织多 agent 团队可能因共识化而削弱专家判断。这会直接影响产品里的 agent 编排、专家路由、审核机制和 eval 设计。

**工具 / 工作流信号**：Google Genkit Agents 与 ADK Go 2.0 给出两条路线：Genkit 更像全栈应用内的 agent primitive，ADK 更像复杂图式工作流和 HITL runtime。GitHub 浏览器工具则把前端调试、表单测试、截图和控制台错误纳入 coding agent 工作流。

**风险 / 限制 / 反例**：今天的风险信号集中在三类：企业成本不可见会导致模型禁用；多 agent 协作可能降低专家输出；高风险行业的 usage policy 会与客户诉求冲突。AI PM 的判断重点应从“能不能做”转向“谁负责、怎样审计、成本如何归因、失败时如何收敛”。
